# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 两位摊主接力改版面

- **交接导出**：导出 `.relay.json` 交接文件，只包含落字用到的字模资料、纸张设置（纸张、方向、网格间距）和作品名，未用库存不写入。
- **接力导入**：先校验身份与版本、格子行列、字模资料；格式旧、落字越界或资料缺失时会逐条说明原因，当前版面与草稿保持原样。
- **合并**：通过后按字符、风格、字号、磨损认同款字模，数量取两边较多的一份；导入版面接到新（本地）字模编号，替换当前版面并另存为一条草稿，页面给出结果摘要。

## 文件分工

- `storage.js`：localStorage 存档读写与初始资料。
- `rules.js`：交接包打包、导入校验、字模合并与版面挂接等业务规则。
- `app.js`：页面渲染、事件、文件读写、校验提示与结果摘要。
