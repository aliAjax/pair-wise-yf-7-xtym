# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 两位摊主接力同一张版面

右侧「草稿与核对」面板提供「接力传档」：

- **导出接力档**：下载 `作品名.relay.json`，只包含落字用到的字模资料、纸张设置（纸张、方向、网格间距）和作品名；未使用的字模库存不会写入。
- **导入接力档**：先检查版本号、纸张格子和字模资料。格式过旧/过新、落字越界、字模或版面资料缺失时，会逐条说明原因，当前版面与已存草稿保持原样。
- 校验通过后，按「字符 + 风格 + 字号 + 磨损」合并重复字模，重复字模数量取两边较多的一份；新字模补入库存，版面重新接到本机字模编号，整体留成一份带「接力档」标记的草稿（不覆盖当前版面，载入该草稿即可继续接力）。
- 面板会显示校验提示与结果摘要（新增/合并字模数、落字数）。

代码按职责分成三个业务文件，均为无依赖的经典脚本：

- `relay-rules.js`：业务规则（格子、字模合并键、导出组装、导入校验、合并）；
- `relay-archive.js`：存档读写（接力档下载与文件解析）；
- `relay-ui.js`：页面接入（入口按钮、校验提示、结果摘要）。

`relay-rules.test.js` 是规则层的 Node 内置测试（不引入任何依赖），运行方式：

```bash
node --test relay-rules.test.js
```
